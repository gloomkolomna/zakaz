# Фирменные материалы

Сюда кладутся файлы для этапа 4 «Брендинг и полировка» (см. `docs/PLAN.md`, раздел 9).

## Что нужно

1. **Логотип** — SVG или PNG от 512 px; если есть — версии для светлого и тёмного фона.
2. **Цвета** — HEX-коды: фон, поверхность, текст, акцент (можно ссылку на брендбук).
3. **Шрифты** — названия или файлы; если нет — подберу близкие аналоги с Google Fonts.
4. **Референсы** — 3–5 скриншотов/ссылок «как должно выглядеть».
5. **Фото товаров и карточек** — JPG/PNG от 1200 px по длинной стороне.

## Как назвать файлы

```
docs/brand/
  logo.svg
  logo-dark.png
  colors.txt        # по строке: роль=#HEX
  fonts.txt         # по строке: роль=Название
  references/       # скриншоты
  products/         # фото товаров (по названию товара)
```

Пока файлов нет — приложение собирается на нейтральной тёплой теме,
брендинг накладывается одним слоем на этапе 4.
