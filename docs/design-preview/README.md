# Дизайн-превью

Статические прототипы интерфейса. Эталон видения — [`DESIGN.md`](../../DESIGN.md),
обзор вариантов — [`variants/index.html`](variants/index.html). Собрано без
сборщика: HTML + CSS + JS, шрифты лежат локально.

## Четыре варианта

| Вариант | Папка | Направление |
|---|---|---|
| **A — выбран** | `index.html` | «Красная нить» — бумага схемы, Literata + Golos, красный акцент |
| B | `variants/b/` | «Ночная смена» — тёмный фон, Unbounded, тёплый свет |
| C | `variants/c/` | «Прайс-лист» — строки-прайс, Onest, ноль скруглений |
| D | `variants/d/` | «Лоскут» — песочные поля, Bitter, мягкие формы |

A выбран 2026-10-26 и развивается: «Мои заказы», **очередь с позицией заказа**,
отмена с подтверждением, «Выполнить» у владельца, редактирование «Вашего
заказа» и плашка отмены в админке. B, C и D — архив выбора: работают, но не
развиваются. Они используют общий движок `shared/core.js` и отличаются только
`config.js` (палитры картинок) и `styles.css`. A живёт отдельным `app.js` —
у него свои экраны заказов.

## Как открыть

Двойной клик по `index.html` (или по любому `variants/*/index.html`).
Экраны переключаются якорем:

| Адрес | Экран |
|---|---|
| `#catalog` | Каталог |
| `#product/1` | Товар |
| `#step/0` | Шаг «Размер» |
| `#step/3` | Шаг «Упаковка» (можно несколько) |
| `#review` | «Ваш заказ» — редактируемая легенда |
| `#success` | Заказ отправлен (с позицией в очереди) |
| `#orders` | Мои заказы: статус + «№ N в очереди» |
| `#order/14` | Заказ: состав, статус, «1-й в очереди», «Отменить заказ» |
| `#order/13` | Пример отменённого заказа |
| `#admin` | Админка: очередь с номерами, «Выполнить», плашка отмены |

Кликается всё: карточки выбираются, степпер меняет количество, «Далее» ведёт
по шагам, на «Вашем заказе» можно менять количество, убирать позиции и
**перевыбирать шаг** — кнопка «Изменить» открывает нижнюю шторку с вариантами,
выбор применяется сразу, «Готово» закрывает. «Отправить заказ» создаёт заказ
№15 и показывает его в «Моих заказах» с номером в очереди. Отмена спрашивает
подтверждение и зажигает плашку в админке (кнопка «Понятно» её гасит).
В админке **стрелки ↑/↓** меняют порядок очереди, кнопка **«Выполнить»**
убирает заказ из очереди — номера остальных сдвигаются, а покупатель видит
новую позицию. ☰ открывает меню.

## Знак

`logo.svg` — игла с ниткой и маленьким крестиком, 24×24, красный `#B02A21`;
в шапке 22 px, он же фавикон. Поиск формы — `logo.html` (варианты на 16–48 px).
Это не «X»: композиция диагональная, крестик — маленький стежок под остриём,
поэтому знак не читается как кнопка закрытия.

## Адаптивность

Оболочка рассчитана на iframe ВК **630×600 … 1000×4050** и мобильный webview
360–430: телефон — одна колонка, 620–879 — две, от 880 — три и двухколоночный
товар. Горизонтальной прокрутки нет; проверено на 390×844, 630×600, 1000×700
(`shots/resp-*`).

## Скриншоты

`shots/` — снимки 390px и 1440px для всех вариантов, снятые puppeteer-core:

```powershell
cd .tools
node shot.mjs
```

## Что здесь плейсхолдер

- **Изображения** — рисованные схемы-трекеры, а не фото товаров. В приложении
  их место займут фотографии 4:5 из админки.
- **Тексты** описаний, состав шагов и цены — пример для плотности; одинаковы
  во всех вариантах, чтобы сравнивать дизайн, а не контент.

## Проверки

- `lint.mjs --app` — 0 FAIL (предупреждения: номера позиций в данных и тире
  в русских текстах — ложные срабатывания).
- `inspect.mjs --app` для A — 0 FAIL / 0 WARN на 1440, 768 и 390: заголовок
  32/28px, Literata + Golos загружены, размеры 12–32px, контраст в норме.
  B/C/D сняты тем же браузером; их шрифты — Unbounded/Onest/Bitter.
