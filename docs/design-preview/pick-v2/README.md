# Шаг: выбор из нескольких — превью

Черновик для утверждения. В приложении пока ничего не менялось: это отдельная
статика, собранная на токенах A и реальных классах `theme.css`.

| Файл | Что показывает |
|---|---|
| [`index.html`](index.html) | Обзор: «сейчас» и «предложение» на 390, 630 и просмотр фото |
| [`rows.html`](rows.html) | Живое превью: строки выбираются, степпер работает, миниатюра открывает фото |
| [`current.html`](current.html) | Текущая вёрстка шага для сравнения |
| [`preview.css`](preview.css) | Стили строк — черновик для переноса в `theme.css` |

## Предложение

- Карточка-плитка 4:5 заменяется строкой: миниатюра 76×76, справа плашка
  с названием и ценой, под плашкой количество.
- Плашка — визуально выделенная область выбора (бумага на белом); выбранная
  строка получает красную рамку, подложку и белую плашку с галочкой.
- Вся строка — выбор, кроме миниатюры и степпера.
- Миниатюра — фото: открывает полноэкранный просмотр с листанием, счётчиком и
  миниатюрами. Галерея под сеткой в шаге больше не нужна.
- Количество: 148×40 на телефоне под плашкой, 120×36 на широком экране справа
  в плашке.
- Одна колонка на всех ширинах: строки не растягиваются и не прыгают по высоте,
  на 390 видно сразу 4 варианта вместо 2.

## Открытые вопросы

1. Миниатюра открывает фото, а не выбирает — оставить?
2. Количество только у выбранных (как в превью) или у всех строк?
3. Убрать галерею под сеткой совсем?
4. На широком экране количество справа в плашке — или тоже под ней?

Фото в превью — демо-снимки из `api/uploads`, скопированы в `img/`, чтобы
папка открывалась отдельно от локальной БД.
