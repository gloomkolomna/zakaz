Четыре направления

Один и тот же продукт — каталог, шаги, легенда заказа, админка — в четырёх визуальных мирах. Все прототипы живые: карточки выбираются, степпер считает, заказ отправляется.

Сравнивать лучше попарно: откройте два варианта в соседних вкладках и пройдите один путь — каталог → товар → шаг → «Ваш заказ» → админка. Внутри каждого варианта в меню есть ссылка «Все варианты дизайна».

Красная нить

Бумага схемы, графит и одна красная нить: выбранное и пройденное отмечается ею. Заголовки — Literata, интерфейс — Golos.

  • Фон — тёплая бумага #F4F5F1
  • Форма — 8 px, 1 px линии, без теней
  • Характер — печатная схема, спокойная точность

Ночная смена

Вечерняя мастерская при лампе: тёмный фон, тёплый светлый текст, широкие заголовки Unbounded. Фото — как светящиеся панно.

  • Форма — 2 px, острые углы, инверсная кнопка

Вариант C

Прайс-лист

Каталог как типографский прайс: строки, правила, крупные имена и цены, маленькие квадратные превью. Один шрифт — Onest.

  • Фон — холодный светлый #F1F1ED
  • Форма — 0 px, только линии и выключка
  • Характер — швейцарская точность, цифры, плотность

Вариант D

Лоскут

Тёплое лоскутное одеяло: мягкие формы, тканевые поля разделов, слэб-заголовки Bitter, шалфейный акцент.

  • Фон — тёплый песочный #F7F2E9
  • Форма — 18–22 px, мягкие карточки
  • Характер — уют, тактильность, женственность
