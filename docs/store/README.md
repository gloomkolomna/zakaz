# Ассеты для VK Mini App

Готовые файлы для карточки мини-приложения в VK. Стиль — вариант A
«Красная нить»: бумага `#F4F5F1`, графит `#1A201B`, красный `#B02A21`,
Literata + Golos Text. Фон сшит клеткой аиды (24 px), без теней и градиентов.
Каталог — **всё для вышивальщиц**: блокноты, календари, настольные игры,
трекеры.

## Фавикон

`favicon-32.png` — тот же знак, но нить короче и толще: на 32 px длинная
дуга сливается с иглой. Файл лежит и в `frontend/public/favicon-32.png`,
вкладка берёт его через `<link rel="icon" sizes="32x32">`.

## Анимированная иконка

96 × 96, 30 fps, 3 секунды, прозрачный фон. Два красных стежка по очереди
вышивают крестик: первый — с 0 по 24 кадр, второй — с 22 по 46, затем пауза
и плавное исчезновение. Это «вышивание», а не спиннер: не читается как
ошибка или «закрыть». Цвет `#B02A21` (0.6902, 0.1647, 0.1294).

Проверен в `lottie-web` (SVG-рендер): кадры 0–90 отрисовываются без ошибок.

## Как пересобрать

1. `docs/store/assets.html` — иконка и сниппет, точные размеры через
   `?a=icon` и `?a=snippet`.
2. `.tools/gen-store.mjs` — снимает иконку, сниппет и четыре экрана
   прототипа `docs/design-preview` в 2× (`raw/`).
3. `.tools/finalize-store.py` — уменьшает до нужных размеров и собирает JPG.
4. `.tools/validate-lottie.mjs` — прогоняет JSON через `lottie-web` и снимает
   кадры для проверки.

```powershell
cd .tools
node gen-store.mjs
..\api\venv\Scripts\python.exe finalize-store.py
node validate-lottie.mjs
```

## Ограничения

- На иконке нет названия: VK показывает имя приложения рядом, а знак
  «игла + нить» остаётся читаемым в 96 px.
- Скриншоты сняты с прототипа (эталон вёрстки), а не с прода: после деплоя
  их можно переснять с живого приложения в тех же размерах.
- Фото товаров на макетах — рисованные плейсхолдеры; с реальными фото
  иконка и сниппет не меняются.
