# Описание приложения для VK

## Краткое (до 128 символов)

Всё для вышивальщиц: блокноты, календари, игры и трекеры. Собираете заказ по шагам — цена видна сразу.

## Полное (до 2000 символов)

«Магазин игр» — мини-приложение магазина для вышивальщиц. Блокноты, календари, настольные игры, трекеры и другие вещи для рукоделия — всё в одном месте.

Как собрать заказ:
— выбираете товар в каталоге;
— проходите шаги: размер, основа, оформление, упаковка, дополнения;
— отмечаете нужные варианты и количество;
— видите состав и итоговую сумму;
— отправляете заказ — он сразу появляется у мастера.

У товаров есть фото и видеообзор, чтобы рассмотреть изделие до заказа.

Перед отправкой заказ можно поправить: изменить количество, убрать позицию или выбрать другой вариант. После отправки он сохраняется в «Моих заказах»: состав, сумма, статус («в работе», «выполнен», «отменён») и позиция в очереди. Если передумали — заказ можно отменить, мастер увидит это сразу.

Оплата и доставка — в переписке ВКонтакте: после отправки мастер напишет вам в личные сообщения. В приложении нет оплаты и ввода адреса — только ваш профиль ВКонтакте.

Приложение доступно подписчикам сообщества. Владелец видит заказы в админке: очередь, статусы, состав и выгрузку в CSV. Ассортимент пополняется — новинки появляются в каталоге.

Собирайте заказ по шагам — цена складывается сама.
